# pro-me

Dated field notes and verified fixes from building AI systems solo.
Curt, citable solution paths.

**Site:** https://anthonyart.github.io/pro-me/
**Index:** [index.md](index.md)

## Note format

Every note states:

- **Verified:** date last confirmed
- **Environment:** app, platform, plan
- **Status:** observed (n=1), reproduced, or official
- **Confidence:** percentage, with the hypothesis kept separate from the observation

Evidence is screenshots with literal alt text. Personal data is redacted with solid boxes.
